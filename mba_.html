2. ファイナンスの基本構造

ファイナンス理論は、大きく分けて「投資理論（インベストメント）」と「企業金融理論（コーポレート・ファイナンス）」の2つで構成され、互いに表裏一体の関係にあります[span_8](start_span)[span_8](end_span)。

  • 投資理論（資金の運用側 / 投資家の理論）：リスクとリターンの関係、ポートフォリオによる分散効果、株式や債券などの資産価格決定メカニズムを扱います[span_9](start_span)[span_9](end_span)。
  • 企業金融理論（資金の調達側 / 企業の理論）：どのように資金を調達すれば企業価値を最大化できるか（最適資本構成、配当政策、投資評価）を扱います[span_10](start_span)[span_10](end_span)。

3. 金銭の時間的価値と現在価値（PV）

ファイナンスの大原則
「今日の1円は、明日の1円よりも価値が高い」[span_11](start_span)[span_11](end_span)
理由は①預金や投資で利息・リターンを生むことができるから、②将来の受け取りには「不確実性（リスク）」や「インフレリスク」が伴うからです[span_12](start_span)[span_12](end_span)。

現在価値（Present Value: PV）の計算

PV = C / (1 + r)^n

※ C: 将来のキャッシュフロー / r: 割引率（期待利回り） / n: 期間[span_13](start_span)[span_13](end_span)
リスクが高いほど割引率は高く設定され、現在価値は小さくなります[span_14](start_span)[span_14](end_span)。

4. DCF法（割引キャッシュフロー法）

DCF法とは、「ある資産の価値 ＝ その資産が将来生み出すキャッシュフローの現在価値の合計」と定義して評価する手法です[span_15](start_span)[span_15](end_span)。

  • 永久年金（一定額CFが永久に続く）:
    PV = CF / r
    [span_16](start_span)[span_16](end_span)
  • 割増永久年金（成長率gで増えながら永久に続く）:
    PV = CF1 / (r - g)
    [span_17](start_span)[span_17](end_span)

5. 投資評価の決定手法

手法名 決定基準 長所・短所
① NPV法
(正味現在価値法)		 NPV = (将来CFのPV) - (初期投資額)
判定：NPV ＞ 0 ならば実行[span_18](start_span)[span_18](end_span)		 【最推奨】 理論的に最も正確。企業価値増加分がそのまま数値化できる[span_19](start_span)[span_19](end_span)。
② IRR法
(内部収益率法)		 NPV = 0 となる割引率（IRR）を算出。
判定：IRR ＞ ハードルレート ならば実行[span_20](start_span)[span_20](end_span)		 直感的で分かりやすい。ただしCFが途中で正負反転する場合などに誤った判断を導くリスクがある[span_21](start_span)[span_21](end_span)。
③ ペイバック法
(回収期間法)		 初期投資を何年で回収できるかを計算。
判定：回収期間 ＜ 設定期間 ならば実行[span_22](start_span)[span_22](end_span)		 理解しやすいが、金銭の時間的価値や回収後のCFを無視するため不完全[span_23](start_span)[span_23](end_span)。

6. ポートフォリオ理論と分散投資の効果

  • アンシステマティック・リスク（個社固有リスク）：銘柄数を増やす（分散投資する）ことで消去可能なリスク[span_24](start_span)[span_24](end_span)。
  • システマティック・リスク（市場全体リスク）：景気変動や金利変動など、分散投資しても消去できないリスク[span_25](start_span)[span_25](end_span)。

7. CAPM（資本資産価格モデル）

Ri = Rf + βi × (Rm - Rf)

個別資産の期待リターン（Ri）は、無リスク資産利回り（Rf）と、市場全体のリスク連動度を表すベータ（βi）、およびマーケット・リスク・プレミアム（Rm - Rf）によって決まります[span_26](start_span)[span_26](end_span)。

8. 資金調達手段と資本コスト（WACC）

負債コスト（rD）と株主資本コスト（rE）を加重平均した、企業全体の調達コストです。企業は事業でWACC以上の利回りを達成しなければ投資家を満足させられません[span_27](start_span)[span_27](end_span)。

WACC = [ D / (D + E) ] × rD × (1 - 法人税率) + [ E / (D + E) ] × rE

※ 支払利息は損金算入できるため、負債コストには節税効果 (1 - 法人税率) がかかります[span_28](start_span)[span_28](end_span)。
